# Android / APK

Проект собирается как Android-приложение через Capacitor. В APK веб-интерфейс находится локально в `www/`, поэтому для запуска приложения не требуется GitHub Pages.

## Что работает без интернета

После хотя бы одного успешного входа и синхронизации на устройстве сохраняется локальная копия семейных данных в IndexedDB.

Без сети доступны:

- просмотр ранее синхронизированных данных;
- добавление, изменение, удаление и восстановление финансовых операций;
- изменение бюджетов;
- создание и изменение регулярных платежей;
- отметка регулярного платежа как оплаченного;
- создание финансовых целей и пополнений;
- архивирование и удаление целей;
- создание и переименование пользовательских категорий и подкатегорий.

Локальные изменения попадают в очередь и отправляются в Supabase после восстановления соединения. Если одна и та же финансовая операция была изменена на другом устройстве, приложение останавливает автоматическую отправку этой записи и показывает конфликт с выбором: оставить серверную версию или отправить локальную.

## Локальный PIN

В установленном APK/PWA можно включить шестизначный PIN через меню `Ещё -> Блокировка PIN`. PIN хранится только на конкретном устройстве в виде PBKDF2-хэша и не заменяет Supabase Auth.

## Сборка

GitHub Actions workflow `.github/workflows/android-apk.yml` автоматически собирает debug APK при изменениях интерфейса, Android-конфигурации или мобильных ресурсов.

Debug-сборки используют стабильный специальный debug-ключ из `mobile-assets/debug-keystore.b64`. Этот ключ не является production-секретом и нужен только для того, чтобы новая тестовая APK могла устанавливаться поверх предыдущей. `versionCode` увеличивается по номеру запуска GitHub Actions.

## Production release

Для постоянной production-подписи нужно один раз создать отдельный release-keystore и сохранить его только в GitHub Actions Secrets:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

Если эти четыре секрета настроены, workflow дополнительно создаёт `family-treasury-release-apk`. Release-keystore нельзя добавлять в публичный репозиторий: потеря ключа или его замена лишит возможности устанавливать обновления поверх уже установленной production-версии.

## Локальная сборка разработчиком

```bash
npm install
npm run mobile:prepare
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

Результат находится в `android/app/build/outputs/apk/debug/app-debug.apk`.
