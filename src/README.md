# Refactor structure

Рабочая GitHub Pages версия переведена с временных `phase*.js` / `phase*.css` и монолитного `app.js` на постоянную модульную структуру.

## Текущая структура

- `src/js/core/runtime.js` — Supabase-клиент, состояние приложения, общие утилиты, загрузка данных и onboarding;
- `src/js/core/start.js` — единая точка запуска после регистрации всех модулей;
- `src/js/core/transaction-form.js` — базовая логика формы операции;
- `src/js/features/` — Обзор, Журнал, бюджеты, аналитика, категории, регулярные платежи, доступ и другие функции;
- `src/js/ui/app-shell.js` — каркас приложения и маршрутизация;
- `src/js/ui/` — навигация, фокус, подсказки и графические декораторы;
- `src/css/app.css` — единая точка входа стилей;
- `src/css/components/` — стили компонентов;
- `src/css/pages/` — стили отдельных страниц;
- `assets/` — изображения и UI-графика.

## Активные feature-модули

- `features/reminders.js` — сроки и ближайшие регулярные платежи;
- `features/transaction-entry.js` — быстрый ввод операции;
- `features/transactions-shared.js` — общие операции редактирования/удаления и отображения транзакций;
- `features/overview.js` — Обзор;
- `features/journal.js` — Журнал;
- `features/categories.js` — категории и подкатегории;
- `features/analytics.js` — аналитика и графики;
- `features/budgets.js` — лимиты бюджета;
- `features/recurring.js` — отображение регулярных платежей;
- `features/recurring-actions.js` — создание, пауза, удаление и внесение регулярных платежей;
- `features/private-access.js` — закрытая семейная авторизация и приглашения;
- `features/access-overview.js` — приглашение супруги из Обзора;
- `features/date-ribbon.js` — пиратская лента дат;
- `features/ui-enhancements.js` — подсказки и дополнительные UX-правки.

## Что больше не загружается сайтом

- `app.js`;
- `phase2-fix.js`;
- все `phase*.js`;
- все `phase*.css`.

Эти старые файлы пока оставлены в репозитории только как резерв до финальной проверки новой структуры.

## Следующие шаги

1. Проверить модульный runtime на всех основных сценариях.
2. Удалить резервные `phase*.js/css` и старый `app.js` после подтверждения стабильности.
3. Удалить неиспользуемые Next.js / Prisma / Docker-файлы текущей GitHub Pages версии.
4. После очистки переходить к мобильной переработке, экспорту Excel/CSV, расширенной аналитике и финансовым целям.
