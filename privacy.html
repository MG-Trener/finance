Политика конфиденциальности «Семейной казны»

«Семейная казна» — приложение для личного семейного учёта доходов, расходов, бюджетов, целей и регулярных платежей. Приложение не является банком, платёжным сервисом, брокером или сервисом кредитования.

Какие данные обрабатываются

  • email и данные авторизации, необходимые для входа;
  • имена участников семейной казны;
  • введённые пользователями доходы, расходы, категории и комментарии;
  • бюджеты, финансовые цели, пополнения целей и регулярные платежи;
  • технические данные, необходимые для синхронизации и защиты доступа.

Приложение не запрашивает номера банковских карт, банковские пароли, PIN-коды карт или данные интернет-банкинга.

Для чего используются данные

Данные используются только для работы приложения: отображения семейного бюджета, синхронизации между разрешёнными устройствами, восстановления истории, расчёта аналитики, обеспечения офлайн-режима и защиты доступа.

Хранение и передача

Серверные данные хранятся в инфраструктуре Supabase. Обмен между приложением и сервером выполняется по защищённому HTTPS-соединению. Для офлайн-режима часть данных может храниться локально на устройстве пользователя в IndexedDB/локальном хранилище приложения.

Мы не продаём пользовательские данные, не используем рекламные SDK и не передаём семейные финансовые записи рекламодателям.

Совместные семейные данные

К одной семейной казне могут быть подключены два аккаунта. Поэтому часть финансовых записей является совместной. При удалении одного аккаунта общие семейные записи могут быть сохранены для второго участника, если их удаление уничтожило бы его собственную историю. Персональные данные удаляемого пользователя обрабатываются отдельно.

Удаление аккаунта и данных

Пользователь может инициировать удаление аккаунта непосредственно в приложении: Ещё → Доступ → Удаление аккаунта. Также доступна отдельная веб-страница для запуска процесса удаления.

Локальные данные на телефоне

После удаления приложения Android удаляет локальное хранилище приложения. Если пользователь хочет удалить локальную копию раньше, это можно сделать через системные настройки Android, очистив данные приложения.

Безопасность

Доступ к серверным данным ограничивается через Supabase Auth и Row Level Security. В установленном приложении можно дополнительно включить локальный PIN. Этот PIN хранится только на устройстве в виде криптографического хэша и не отправляется на сервер.

Изменения политики

Политика может обновляться вместе с развитием приложения. Актуальная версия всегда публикуется по этому адресу.
