# Семейная казна

**Семейная казна** — веб-приложение для совместного учета доходов и расходов семьи из двух человек.

Интерфейс оформлен в атмосферном пиратском стиле: тёмное море, латунь, дерево, компасы, канаты и другие морские элементы. При этом основной акцент сделан на быстрый ежедневный ввод операций и понятную аналитику.

## Онлайн-версия

Приложение опубликовано через GitHub Pages:

https://mg-trener.github.io/finance/

## Основные возможности

- общий семейный баланс;
- раздельная статистика мужа и жены;
- доходы и расходы;
- быстрый ввод операции с автоматической датой и временем;
- выбор участника семьи через переключатель;
- категории, зависящие от типа операции;
- подкатегории, зависящие от выбранной категории;
- запоминание последних используемых категорий;
- журнал всех операций;
- поиск, фильтры и сортировка в журнале;
- редактирование и удаление операций;
- аналитика по доходам и расходам;
- сравнение показателей двух участников семьи;
- структура расходов по категориям;
- бюджеты и месячные лимиты;
- регулярные платежи;
- напоминание о регулярном платеже за 3 дня до даты;
- визуальный индикатор напоминания в левом меню;
- пиратская лента выбора даты в Обзоре;
- кнопка «Сегодня» для возврата к текущей дате;
- адаптивный интерфейс для ПК и мобильных устройств.

## Доступ и безопасность

Приложение рассчитано на одну семью из двух пользователей.

- первый пользователь создаёт семейную базу;
- второй пользователь присоединяется только по одноразовой ссылке-приглашению;
- приглашение действует 7 дней;
- семья ограничена двумя авторизованными аккаунтами;
- обычная свободная регистрация отключена;
- каждый пользователь входит под своим email и паролем;
- данные семьи защищены Row Level Security в Supabase;
- посторонний пользователь не может получить доступ к данным семьи.

Важно: GitHub Pages является публичным статическим хостингом, поэтому сам адрес сайта доступен из интернета. Защита семейных данных реализована через авторизацию Supabase и политики RLS.

## Архитектура

Текущая версия — статическое клиентское приложение без отдельного backend-сервера.

### Frontend

- HTML;
- CSS;
- Vanilla JavaScript;
- Chart.js;
- адаптивная верстка;
- GitHub Pages.

### Backend / база данных

Используется Supabase:

- PostgreSQL;
- Supabase Auth;
- Row Level Security;
- RPC-функции для приглашения второго участника;
- облачное хранение семейных данных.

## Основные сущности базы данных

- `profiles` — профили пользователей;
- `families` — семейные базы;
- `family_users` — пользователи семьи;
- `people` — муж и жена как участники финансового учета;
- `categories` — категории доходов и расходов;
- `subcategories` — подкатегории;
- `transactions` — финансовые операции;
- `budgets` — месячные бюджеты и лимиты;
- `recurring_payments` — регулярные платежи;
- `family_invites` — одноразовые приглашения второго пользователя.

## Основные разделы приложения

### Обзор

Главный рабочий экран:

- ввод новой операции;
- семейный баланс;
- последние операции;
- бюджеты месяца;
- ближайшие регулярные платежи;
- краткая статистика мужа и жены.

### Журнал

Полная история операций:

- поиск;
- фильтр по периоду;
- фильтр по человеку;
- доход / расход;
- категории;
- сортировка;
- редактирование;
- удаление.

### Аналитика

- динамика доходов и расходов по месяцам;
- структура расходов;
- сравнение участников семьи;
- визуальная аналитика через Chart.js.

### Бюджеты

Позволяет задавать месячный лимит для категории и видеть:

- сколько потрачено;
- сколько осталось;
- процент использования бюджета;
- превышение лимита.

### Регулярные платежи

Можно создавать шаблоны повторяющихся платежей с указанием:

- участника семьи;
- типа операции;
- суммы;
- дня месяца;
- категории;
- комментария.

За 3 дня до ближайшей даты пункт «Регулярные» начинает привлекать внимание и показывает количество приближающихся платежей.

### Категории

- системные категории;
- пользовательские категории;
- подкатегории;
- добавление и редактирование собственных элементов.

### Доступ

Раздел управления семейным доступом:

- отображение подключённых пользователей;
- создание одноразовой ссылки для второго участника;
- статус приглашения;
- ограничение семьи двумя аккаунтами.

## Локальный запуск

Отдельный сервер для текущей версии не требуется.

Можно просто открыть `index.html` через локальный HTTP-сервер, например:

```bash
python -m http.server 8000
```

После этого открыть:

```text
http://localhost:8000
```

Для полноценной работы нужен доступ к настроенному проекту Supabase.
