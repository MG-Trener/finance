# Семейные финансы

Современное веб-приложение для учета доходов и расходов семьи мужа и жены.

## Возможности первой версии

- общий семейный баланс;
- отдельные показатели мужа и жены;
- доходы и расходы;
- категории, зависящие от типа операции;
- подкатегории, зависящие от выбранной категории;
- быстрый ввод операции;
- фактическая дата и время операции;
- история операций по месяцам;
- сводка начиная с 2026 года;
- структура расходов по категориям;
- PostgreSQL как собственная база данных;
- Prisma ORM;
- адаптивный русскоязычный интерфейс.

## Стек

- Next.js
- React
- TypeScript
- PostgreSQL
- Prisma
- Docker Compose

## Локальный запуск

1. Установить Node.js 22+ и Docker.
2. Скопировать `.env.example` в `.env`.
3. Запустить PostgreSQL:

```bash
docker compose up -d
```

4. Установить зависимости:

```bash
npm install
```

5. Создать структуру БД:

```bash
npm run db:push
```

6. Заполнить стартовые категории:

```bash
npm run db:seed
```

7. Запустить приложение:

```bash
npm run dev
```

После этого приложение будет доступно на `http://localhost:3000`.
