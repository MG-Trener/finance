# Income coin sound

`income-coins.wav` is an adapted excerpt of **Coin Spill** by clairinski (Freesound), downloaded from Pixabay.

- Source: https://pixabay.com/sound-effects/film-special-effects-coin-spill-105867/
- License: https://pixabay.com/service/license-summary/
- Adaptation: silence-trimmed, cropped to 1.75 seconds, converted to mono PCM WAV, normalized with headroom, and given short fade-in/fade-out envelopes for use as an income confirmation sound.
